# 晴游 · 五图界面介绍

替代上一版仍含地图的宣传材料。共五张 1080 × 1440 图，保留真实界面和必要数据署名，不含地图或站外入口。普通词语并不是已证实的触发原因，详见 [逐项复核](content-review.md)。

- `overview.png`：五图总览。
- `exports/`：按编号使用的五张成图。
- `post.md`：可复制文案；AI 装饰插画与示例天气说明须一并保留。
- `sunseek-xiaohongshu-ui-story.zip`：五张图和文案的本地下载包。
- `content-review.md`：规则来源、适用范围、原六图与新五图检查结果。
- `ocr-review.json`：旧六图与新五图的本机 OCR / 条码识别记录，仅辅助人工复核。

本版聚焦真实设计和交互内容，不承诺通过审核或恢复流量。发布时按真实用途、合作关系及平台要求作相应声明，包含封面 AI 插画声明。

`capture.py` 只从本地明确演示模式截取偏好面板，屏蔽全部外部请求。`render.py` 从本地文件导出素材。`ocr.swift` 用 macOS Vision 框架检查图片中的文字和条码；这些步骤均未请求天气、数据库或小红书账号数据。
