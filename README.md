# 晴游 SUNSEEK

按出行日期和天气心情寻找中国目的地的响应式网站。使用原生 HTML、CSS、JavaScript，不需要安装前端依赖或配置 API 密钥。

## 运行

在项目目录执行：

```sh
python3 -m http.server 4173
```

浏览器打开 `http://localhost:4173`。也可以直接打开 `index.html`，但建议使用本地服务器。将整个目录部署到任意静态网站托管服务即可上线。

## 功能

- 未来 16 天内自选出发、返程日期，提供本周末与未来 7 天快捷选择。
- 晴天、看雪、听雨、清凉四种天气偏好；每日最高温范围、每天都匹配、地区筛选和三种排序。
- 48 个城市的逐日预报；SVG 中国省份地图、天气标记、缩放、放大后的拖动和城市详情。
- 按天气匹配度推荐，点击「查看全部推荐」浏览全部结果。
- 「去过了」标记和笔记存入 localStorage，可在折叠的足迹区域查看或移回推荐；默认优先展示未去过的目的地。
- 城市搜索，支持城市名、省份、地区及英文 ID；⌘K / Ctrl+K 打开搜索。
- 键盘操作、原生对话框、移动端布局和减少动态效果偏好支持。

## 数据与边界

天气使用 Open-Meteo Forecast API，通过浏览器发出三批请求，每批 16 城市，获取未来 16 天的逐日天气、最高/最低温、降水概率、雨雪量及最大风速。日期采用 Asia/Shanghai。免费接口适合非商业原型；正式商用前需核实服务许可、配额及可用性，并配置适用服务。城市预报在本机缓存 1 小时。

数据加载中或全部连接失败时，界面使用**显著标识的确定性示例数据**，不冒充真实预报；部分请求成功时只推荐成功且日期完整的城市，不混合示例数据。详情、地图说明和数据状态均标示数据性质。超出可预报日期、缺少任何必要字段或缺少选定日期的城市不推荐。

匹配度 = 匹配天数占比 × 70 + 温度舒适度 × 20 + 风速舒适度 × 10。舒适温度中心：晴天/听雨 22°C、清凉 20°C、降雪 −3°C。晴好天气为 WMO 0/1/2 且日降水少于 1mm；降雪依实际降雪量与代码；细雨偏好为非强降雨代码、降水量在 0–20mm；清凉要求最高温 15–25°C、日降水少于 5mm、10 米最大风速低于 30km/h。

所选日期任一天出现冻雾、冻雨、强雨雪、雷暴代码，或日降水 ≥ 50mm、日降雪 ≥ 15cm、10 米最大风速 ≥ 50km/h，则排除。**这些筛选不等于官方气象预警，也不能保证旅行安全**；山地、景区、道路及积雪状况仍需单独核实。地图着色仅是该省已覆盖城市的平均匹配天数占比，不推断整个省份天气。无采样城市的省份使用灰色。

地图数据来自阿里云 DataV，保存在 `assets/china.js`；图片来自 Unsplash，作为旅行意境配图，并非对应城市的实景。

记录保存在当前浏览器，不含账号、跨设备同步或服务器数据库。浏览器限制存储时会提示仅作临时保存。

## 文件

- `index.html`：页面结构、对话框和 SVG 图标
- `styles.css`：布局、主题、响应式样式
- `app.js`：天气接入、筛选排序、地图交互和足迹保存
- `assets/`：中国地图数据、本地风景图片及站点图标

## 浏览器验收

本地服务器运行时，安装 Python Playwright 及其 Chromium 后执行 `python3 tests/smoke.py`。测试采用固定天气响应验证筛选、危险天气排除、日期校验、足迹持久化、搜索、地图交互、离线标记及五种屏幕宽度。
