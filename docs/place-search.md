# 地点搜索与台湾采样点

更新于 2026-11-14。本功能与备份迁移、固定推荐范围一并归档于 v0.6.0。

## 入口和行为

页头、地图右上角与添加地点共用 `#search-dialog`。添加地点会带入已填写名称。地区结果切换地图，已收录地点直接打开，额外地名先预览天气、显式保存后才进入个人地点。Enter 打开首项，方向键移动结果，ESC 关闭。已有基础地点不会因在线服务未返回而消失。

`search.js` 对所有来源使用同一相关度排序：名称完全匹配优先于别名、去常见末尾类型后的匹配、前缀/包含；支持省份＋地点、所属市＋地点、省份＋所属市＋地点，以及空格分开的归属词。输入的岛屿后缀提高岛屿实体的相关度。同名结果保留行政归属和实体类型，不合并城市、区县、山峰与岛屿；已知 GeoNames ID 或同省同名城市实体复用基础地点。

通用尾词折叠只在剩余至少两个字时生效，如市、县、区、镇、岛、山等；因此“黄山”保留原名，“花鸟岛”可找到源数据中的“花鸟山”（岛屿）。此处没有为用户列举的县市编写查询特判。不实现任意拼写纠错，不保证每个别名都已收录。

在线补充仍使用 Open-Meteo / GeoNames，停顿 450 ms 后查询，每次最多 100 条；对已识别的强相关实体采用其地点名称查询，保留“景德镇”这样的完整专名；否则从统一行政索引推导归属前缀，取地点词查询后再按完整输入排序。已知归属时带 countryCode，保留 CN/HK/MO/TW 结果。提供方仍受名称匹配与结果数量上限限制，详见 [官方搜索接口](https://open-meteo.com/en/docs/geocoding-api)。取消、关闭或更改查询会隔离旧响应；在线失败不移除本地结果。

## 搜索索引和天气候选独立

- `assets/search-places.json` 包含 25,569 条地名，约 2.94 MB。首次打开搜索才加载，当前页面复用；失败可重试。不会在首屏加载，也不会把这些记录全部请求天气。
- 范围是 GeoNames CN/HK/MO/TW 的 ADM2/ADM3、行政驻地 PPLC/PPLA/PPLA2/PPLA3/PPLA4、ISL/ISLS 岛屿与 MT 山峰；香港澳门另含 ADM1 和 PPL。源库其余大量普通村落不内置，仍可在线查找或手动添加。
- 汉字别名用 OpenCC 生成简繁形式；保留源名称与主要拉丁转写。运行时不需要 OpenCC。
- 相同归属文本用上下文表去重。JSON 中 `rows` 字段依次为 GeoNames ID、显示名、别名、纬度、经度、省级代码、上下文编号、要素类型、人口、来源国家代码；`contexts` 为检索归属别名、显示归属、组合路径别名。
- 天气目录共 506 点，仍默认仅 48 个精选和个人地点。只有主动选择全库、展开省份或选中具体地点才增查天气。搜索记录不占个人地点配额，预览不会持久保存。

## 台湾 22 县市

`assets/taiwan-places.js` 使用 GeoNames 22 个 ADM2 县市身份，天气坐标取同一行政分组的 PPLC/PPLA/PPLA2 驻地，不采用整县几何中心。优先选择与县市同名的驻地，再按源人口排序。保留 `geoId`、参考点 `sampleGeoId` 和名称，详情说明天气只代表参考采样点。台北复用原精选地点和既有坐标/图片，新增其余 21 点。

包含新北、台北、桃园、台中、台南、高雄、基隆、新竹市、嘉义市，以及新竹县、苗栗、彰化、南投、云林、嘉义县、屏东、宜兰、花莲、台东、澎湖、金门、连江。新竹市/县、嘉义市/县分别保留。金门采样点金城的源记录也含“晋城”别名，显示采用源别名“金城”；这是数据标注选择，不是查询改写。

台湾视图将这些内置参考点计入投影视野，金门/连江不因靠近大陆海岸而丢出视野。离岛预览保留 GeoNames 的 TW 来源归属，源坐标与所属省份未被修改时允许与粗略底图边界不同。原 DataV 台湾下级边界仍为空，没有生成虚构行政边界。地图默认仍关闭额外圆点；采样点数量与同时可见标签数不等同。

## 来源、许可与重建

数据来自 [GeoNames 官方导出](https://download.geonames.org/export/dump/)，字段和许可见 [官方说明](https://download.geonames.org/export/dump/readme.txt)，采用 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)。派生索引进行了筛选、行政关联、简繁转换与采样点选择；搜索页脚和关于窗口均有署名。GeoNames 不保证数据完整或实时，历史别名及行政资料仍需核对。

JSON metadata 保存四份源 ZIP 的 URL、SHA-256、下载日期和选取类型。源 ZIP 不入库。更新时下载 CN/HK/MO/TW.zip 为 `/tmp/sunseek-geonames-{代码}.zip`，然后：

```sh
python3 -m pip install --target /tmp/sunseek-build-deps opencc-python-reimplemented
PYTHONPATH=/tmp/sunseek-build-deps python3 scripts/build_search_places.py /tmp
```

脚本同时生成搜索 JSON 与台湾 JS；正常浏览无需构建、Python 或第三方运行依赖。更新后检查目录数量、采样坐标、同名关系与许可信息。
