# 手机交互、可读性与搜索滚动

归档于 v0.7.0。用户当前安排为保留网页修改，不更新腾讯云测试站；Git 代码归档和公开仓库已明确授权。此前搜索分区、节流与部署准备也一并归档。

## 地图

- 单指在地图上上下滑动，交给浏览器滚动页面；放大后单指仍滚动页面。
- 双指在地图上捏合缩放，或双指平移放大后的地图；缩放以双指中心为锚点，限制在 1–2.5 倍及原有平移边界内。
- 触摸缩放只变更地图变换，不改变浏览器页面缩放；地图外仍保留浏览器正常缩放能力。
- 双指与滑动结束时抑制同一次手势产生的误点击，不会误进入省份或选点；下一次单指轻点仍可打开地点。
- 桌面保留放大按钮与鼠标拖动。鼠标和触摸使用 SVG 坐标换算，适配 viewBox 留白与不同比例。

根因是 SVG 原先设置 `touch-action:none`，同时只有鼠标式的单指拖动逻辑。现在改为 `pan-y`，仅在双指触摸期间阻止浏览器默认行为；不拦截普通单指滚动。

## 文字、图片与工具栏

用户反馈放大全局字体影响协调性，本轮恢复原有字号比例（正文 14px、桌面偏好标题 12px）。仅搜索输入框保留 16px，减少 iOS 聚焦输入框后的自动放大。地图标记继续采用原碰撞口径。用户进一步明确需要加宽的是“你的好天气目的地”推荐列表中的照片。v0.7.0 后续修正将选择器限定在 `#recommendation-list`：桌面侧栏（761px 及以上）和常见手机均为 112px，360px 及以下窄屏为 100px；481–760px 的上图下文布局保持整列宽度。覆盖旧样式在部分窗口将照片压到 65–76px 的问题，并撤回对“全部推荐”图片的附带加宽。地图尺寸与标记没有调整。手机顶部新增紧凑“关于”文字，访问同一个关于晴游窗口；页脚和关于窗口提供 GitHub Star 链接，不加载远程计数。

桌面面包屑与按钮采用两列。手机面包屑一行、操作按钮独立一行并左对齐；重试/地图选点/添加地点保持同一排，说明段落独立换行，不推动按钮。操作按钮至少 40px 高。

## 搜索与键盘

- 将本地和在线列表放进同一个 `#search-scroll` 滚动区，移除嵌套的独立滚动；原有本地优先与在线分区继续保留。
- 输入区与页脚保持可见，结果区可收缩和触摸滚动；Visual Viewport 高度/偏移改变时重新适配位置与最大高度。
- 打开对话框时保存页面位置并固定 body，关闭时恢复原有样式和位置；弹窗切换也经过同一锁定接口。`overflow:hidden` 不再是唯一的背景锁定措施。
- 搜索滚动不会穿透到背景。按原有 40 条分批展示本地结果，到全部本地结果末尾再参与在线触发判断；1 秒停笔、输入法保护、会话缓存规则不变。

## 验证与限制

`tests/mobile_interaction.py` 使用 Chromium 原生 CDP 触摸事件，实际检查页面单指滚动、双指地图缩放/平移、浏览器缩放不变、无误选、真实触摸搜索滚动及背景固定；检查 360/390/768/1024/1440px 文字和工具栏布局，并覆盖桌面鼠标拖动。

软键盘通过缩小可视区域来验证弹窗几何与滚动空间，不能替代 iOS/Android 真机键盘。更新线上后仍请用原手机确认键盘、惯性滚动与浏览器地址栏变化时的手感。截图在 `/tmp/sunseek-readable-layout-*` 和 `/tmp/sunseek-search-keyboard-size.png`，不入库。

v0.7.0 完整 16 组回归均通过，已检查手机/桌面、键盘尺寸及 320–1440px 的外观截图。CLI 已返回登录成功；用户暂缓网页发布，当前线上仍为先前版本。

后续图片宽度修正通过 `tests/presentation.py` 的 12 种窗口检查（320–1440px），已查看 390px 手机和 1024px 电脑截图；没有更新腾讯云。
