# 腾讯云 CloudBase 部署与额度评估

核对时间：2026-11-14。用户已确定腾讯云作为部署目标，初期预计每天 50 人以内。用户已通过文件上传部署 [腾讯云测试站](https://sunseek-noisy-sole-d5ganycu813519dcc.webapps.tcloudbase.com)，首次真实线上验收见 [记录](deployment-check-2026-11-14.md)。我们未登录用户腾讯云账号、变更资源/套餐或绑定域名。搜索节流、手机交互和命令工具已归档于 v0.7.0，网页改动尚未同步测试站。

## 当前套餐与使用边界

根据腾讯云 [资源点套餐表](https://cloud.tencent.com/document/product/876/140498) 和 [免费体验活动规则](https://cloud.tencent.com/document/product/876/75213)：

- 新版免费体验版为每月 3,000 资源点。6 个月是有效期，支持到期前一个月内手动续期，不是六个月无限流量。
- 免费版不支持加购资源包或开启超限按量，额度之外不能假设服务可继续。
- 静态托管流量 210 点/GB，静态存储 3.94 点/GB/天。若几乎只使用静态托管，流量理论上限约 `3000 / 210 = 14.3 GB/月`，还需扣除存储及任何其他实际用量。
- 官方上海地域套餐表列出免费环境自定义域名为 0，环境 QPS 为“仅支持体验”，云函数固定 256 MB/3 秒。这些能力不能由月流量额度推导替代。用户实际活动/地域权益需要在控制台核对。
- 个人版当前活动价 19.9 元/月（连续包月，实际价格以购买页为准），每月 40,000 点，自定义域名 1 个；不需要为当前纯静态网站购买云服务器。

[静态托管文档](https://docs.cloudbase.net/hosting/introduce) 说明静态资源使用 CDN 分发。[管理说明](https://docs.cloudbase.net/hosting/manage) 明确默认域名用于开发测试且有限频；当前 [默认域名中间页说明](https://docs.cloudbase.net/service/alias) 采用访问确认提示，默认域名不再硬性续期，环境自身套餐有效期另算。免费额度可支持小范围体验，不等于具备长期正式对外域名与服务保障。

大陆自定义域名、HTTPS 和实际绑定资格在选定环境后按 [官方域名指引](https://docs.cloudbase.net/service/access-static-hosting) 核对。不要把测试域名视为正式生产域名，也不要据旧文章宣称永久免费或无限流量。

## 本站的压力分布

| 操作 | 运行/请求位置 | 腾讯云侧消耗 |
| --- | --- | --- |
| 首页、照片、地图和地名索引 | 静态托管/CDN 下载 | 文件存储与下行流量 |
| 地图投影、天气评分、本地地名匹配 | 用户浏览器 | 无云函数、数据库计算 |
| 在线地名搜索 | 浏览器直连 Open-Meteo Geocoding | 当前不经过腾讯云计算/数据库 |
| 天气预报 | 浏览器直连 Open-Meteo Forecast | 当前不经过腾讯云计算/数据库 |
| 足迹、个人地点、收藏和备份 | 浏览器存储/本机文件 | 无数据库读写与同步 |

因此初期主要关注静态流量、测试域名的可用性与第三方接口配额。当前不需要为了部署增加常驻 Node 服务、云数据库或 SDK。

## 按实际资源测算

本机 Python 静态服务器不压缩传输，Chromium 390/1440px 新上下文，天气接口使用固定测试响应；只统计同源资源 `encodedBodySize`：

- 冷启动首页：1,242,420 bytes，约 1.24 MB，17 个同源资源请求。
- 首次输入至少两个字检索后：累计 4,186,492 bytes，约 4.19 MB。新增本地地名 JSON 为 2,944,072 bytes；此文件只加载一次，输入并不会反复下载。
- 同一 JSON 本机 gzip -9 后为 889,886 bytes，约 0.89 MB。这是压缩潜力，不代表腾讯云已配置或已实测压缩。
- 全量运行文件约 15 MB，含所有城市卡片/详情图和所有省份细线；不会在首页一次加载全部文件。按上述存储单价估算每月约 2 点，实际以控制台计量为准。

以下为每人每天一次冷访问、每月 30 天的近似估算；不计浏览器缓存/HTTP 压缩，不含额外省界/详情图等浏览行为，第三方天气流量不算入本站静态托管流量：

| 每日访问次数 | 只打开首页 | 每次都打开搜索 |
| --- | --- | --- |
| 50 | 约 1.9 GB/月，390 点 | 约 6.3 GB/月，1,320 点 |
| 100 | 约 3.7 GB/月，780 点 | 约 12.6 GB/月，2,640 点 |
| 200 | 约 7.5 GB/月，1,570 点 | 约 25.1 GB/月，5,280 点 |

这些是用量估算，不能用来保证并发承载或可用性。按用户预计的每天 50 人，流量大致足够试用，并有一定余量；重复访问、缓存与压缩通常能进一步减少传输，反复冷加载、更多图片和被外链访问会增加流量。正式访问量以腾讯云用量页为准，用量统计可能有延迟。

## 减少请求：当前已完成

- 本地地点即时检索，在线独立分区，不改变本地排序。仅打开空搜索窗口不下载扩展地名 JSON，首次输入至少两个字才加载，当前页面复用。
- 自动在线查询必须同时满足：输入至少两个字、中文输入法已完成、停笔 1 秒、本地索引已加载完成（或明确失败），并且本地无匹配，或用户滚动至全部本地结果末尾。
- 本地结果每次展示 40 条，滚动/按钮继续展示后续本地结果；还有本地结果时先扩展本地列表。
- 在线按钮与无结果时的 Enter 可立即提交；有本地结果时 Enter 仍打开首项。单次请求进行中禁止重复提交。
- 更改文字、关闭搜索会取消并隔离旧请求；仅取消请求不代表供应商已取消计量，因此从触发端减少请求更有效。
- 同一页面会话缓存在线结果：有返回记录 30 分钟、真正空响应 2 分钟，最多 50 项；失败不缓存。重复查询优先复用，不新增持久存储键。
- 天气仍采用原有逐地点缓存、默认精选范围、16 点串行批次和限流后停止规则。

## 减少流量与天气接口压力：后续配置

1. **配置并验证 HTTP 压缩与缓存。** 上线后检查 `Content-Encoding`、`Cache-Control` 以及实际传输量。长期缓存资源应配合内容哈希或版本化 URL；当前同名脚本不要直接设置一年不可变缓存。HTML 保持短缓存或协商缓存，发布后核对新资源。ZIP 压缩只减少上传包体积，不等于浏览器 HTTP 压缩。
2. **保持纯静态与按需加载。** 不在首屏请求全库，不为了使用 CloudBase 而增加数据库、匿名登录或常驻计算。城市图片已是 WebP，详情图按需请求。
3. **先核对默认域名/自定义域名与用量提醒。** 免费版的域名限制可能先于流量额度成为正式发布障碍。建议小范围试用，流量预算预留约 20% 余量，并核对控制台支持的监控提醒。
4. **访问量增加后采用共享天气缓存。** 让多个访问者复用同一地点的新鲜预报，或由定时任务生成带来源/逐地点时间戳的公共天气 JSON，经 CDN 分发。缺失/过期时仍按既有规则处理，不能把过期数据称为实时；该方案尚未实现。

[Open-Meteo 免费条款](https://open-meteo.com/en/terms) 限制非商业用途，并列出每分钟 600、每小时 5,000、每日 10,000 调用限制，按应用与 IP 限流；[计量说明](https://open-meteo.com/en/pricing) 还按地点数量、变量和日期范围折算，超过 10 个变量或两周会增加计量。当前 48 个地点合并成 3 个 HTTP 请求，不能当成只消耗 3 个 API 调用额度。若按每点至少一次计量粗估，50 次冷启动已有约 2,400 点次，当前 16 天与较多变量会进一步增加；扩展 506 点或反复刷新也增加消耗，不能据此保证免费天气接口足够所有访问。

定时缓存任务同样要控制总刷新量：48 点每小时刷新一次约 1,152 点次/天，而全库 506 点每小时刷新约 12,144 点次/天，后者尚未计变量/天数就已超过每日 10,000 的数量级。免费云函数 3 秒限制也不适合直接承接当前可能等待 22 秒、含多批的天气请求。选择共享缓存方案时再核对运行方式和额度，不要将所有浏览器请求简单转发到单一函数/IP。

当前没有广告、收费会员或商业推广；后续如转商业用途需按供应商许可重新选择天气服务。这份评估不代表已购买任何付费服务。

## 可审核的部署包

```sh
python3 scripts/package_static.py /tmp/sunseek-tencent-static.zip
```

只打包 8 个运行入口（HTML、CSS 与 6 个 JS）和 `assets/`；排除 Git、开发文档、测试、脚本、环境配置与下载源 ZIP。脚本同时校验 ZIP 完整性并输出文件数、原始大小和 SHA-256。保留资源自身的署名清单。可用控制台上传代码包；无需先安装 Node 或新框架。

发布前确认环境 ID/地域、套餐及静态托管权限、域名与 HTTPS；在明确目标环境后使用 [纯静态项目部署指引](https://docs.cloudbase.net/hosting/web-hosting-static) 上传。首次从 localhost 换到线上域名时浏览器存储属于不同来源，已有本机旅行记录可以先导出再在新地址导入。

## 本轮验证

新增请求节流专项、原搜索、地点管理、主流程、旅行预览、日期规划和备份共 7 组相关测试通过。检查了手机/桌面分区截图，并从实际 ZIP 在子路径下预览通过地图资源、天气测试响应、本地索引与在线补充。随后已在用户发布的真实测试站验收通过，观察到当前响应未使用 HTTP 压缩、缓存头为 300/600 秒；详情见 [线上验收记录](deployment-check-2026-11-14.md)。用户控制台的实际套餐、域名权限和剩余额度仍未读取，国内多网络与平台限频阈值尚未验证。
